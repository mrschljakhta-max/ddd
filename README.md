# Game Room — Дурень і хрестики-нулики

Дві браузерні гри проти локальної суперниці-ШІ з єдиним гардеробом дорослої вигаданої персонажки.

**Сайт:** https://mrschljakhta-max.github.io/ddd/

## Ігри

### ♠ Підкидний дурень
- 36 карт, козир, підкидання й захист.
- Власна статистика партій.
- Компактний адаптивний картковий стіл.

### ✕◯ Хрестики-нулики
- Поле 3×3: ти ставиш X, суперниця — O.
- 3 складності: легка, звичайна й безжальна (мінімакс).
- Початковий хід чергується в нових партіях.
- Окремо рахуються перемоги, поразки й нічиї.

## Спільна механіка
- Твоя перемога знімає один шар вбрання; перемога суперниці повертає один шар.
- Нічия нічого не змінює.
- П'ять етапів; після останнього залишається закрите базове вбрання.
- Гардероб і результати зберігаються локально в браузері.

## Архітектура
- `index.html` — навігація між іграми, ігрові панелі й SVG-персонажка.
- `styles.css` — оформлення й адаптивний дизайн.
- `game.js` — карткова гра та спільний механізм гардероба.
- `tictactoe.js` — хрестики-нулики, локальний ШІ, складність, статистика.

## Важливо
Зараз це автономні ігри проти локальних алгоритмів, а не особисто ChatGPT через OpenAI API. Фотореалістичну графіку ще не додано.
