# Картковий двобій — Game Room

Гра в підкидного дурня (36 карт) проти локального ШІ з режимом зміни вбрання дорослої вигаданої персонажки.

## Сайт
https://mrschljakhta-max.github.io/ddd/

## Функції
- Козирі, відбиття, підкидання та добір карт за правилами підкидного дурня.
- Зміна п'яти шарів одягу після перемог і поразок. Базове закрите вбрання залишається.
- Адаптивний стіл, без горизонтального прокручування усієї сторінки.
- Ігрові коментарі, звук (за бажанням), історія ходів.
- Рахунок і гардероб зберігаються в локальному сховищі браузера.

## Файли
- `index.html` — структура та SVG-персонажка.
- `styles.css` — стилі та адаптивність.
- `game.js` — правила, колода, суперник і статистика.

## Обмеження
Це автономна гра проти **локального алгоритму**. ChatGPT/OpenAI API **не підключено**.
Результати не синхронізуються між пристроями. Реалістична фотографічна графіка ще не додана — зараз використовується деталізована векторна ілюстрація.
